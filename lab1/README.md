# Практическая работа: Scikit-Learn + Seaborn

Лабораторная работа по машинному обучению с использованием библиотеки **Scikit-Learn**.

**Использован материал:** Л1. Знакомство с библиотекой Scikit-Learn [Плас. Python для сложных задач (2018) с.391-с.408]

---

## Задания

В файле `tasks.py` реализованы 5 задач, соответствующих пунктам задания:

| Код  | Пункт ТЗ | Задача |
|------|----------|--------|
| `2a` | п.2а | Модель линейной регрессии (синтетические данные) |
| `2b` | п.2б | Модель классификации набора данных Iris |
| `2c` | п.2в | Модель понижения размерности Iris (PCA) |
| `2d` | п.2г | Модель кластеризации Iris (KMeans) |
| `5`  | п.5  | Распознавание рукописных цифр (`digits`) |

В каждой из задач **2a–2d** выполнены процедуры п.1:

- **1a** — сгенерировать синтетический набор данных / скачать Iris через `seaborn.load_dataset()` в виде `pandas.DataFrame`;
- **1b** — выбрать класс модели (`LinearRegression`, `LogisticRegression`, `PCA`, `KMeans`);
- **1c** — выбрать гиперпараметры модели;
- **1d** — сформировать матрицу признаков `X` и целевой вектор `y` в формате, подходящем для `fit()`;
- **1e** — обучить модель (`fit`);
- **1f** — выполнить предсказание меток для новых данных (`predict` / `transform`).

В каждом задании (п.3) выполнена визуализация **исходных данных** и **результатов обучения** средствами **Seaborn**, включая **парные графики** (pairplot) для Iris.

В задании **5** выполнены подпункты:

- **5a** — загрузить и визуализировать встроенный набор рукописных цифр из `sklearn.datasets`;
- **5b** — понизить размерность признаков с 64 до 2 с помощью метода без учителя (PCA);
- **5c** — применить алгоритм классификации (`LogisticRegression`) к исходному набору;
- **5d** — оценить точность модели (`accuracy_score`, `classification_report`);
- **5e** — построить матрицу различий (`confusion_matrix`) и нарисовать её через `seaborn.heatmap`.

## Требования

- **Python** 3.10 или новее
- **Библиотеки:**
  - numpy
  - pandas
  - matplotlib
  - seaborn
  - scikit-learn

Полный список — в файле `requirements.txt`.

---

## Установка

### 1. Клонировать / скачать проект

Скачайте папку с файлами `tasks.py` и `requirements.txt`.

### 2. Установить зависимости

Из папки с проектом:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Из папки, где лежит `tasks.py`:

```bash
python tasks.py 2a      # линейная регрессия
python tasks.py 2b      # классификация Iris
python tasks.py 2c      # понижение размерности Iris (PCA)
python tasks.py 2d      # кластеризация Iris (KMeans)
python tasks.py 5       # распознавание рукописных цифр
python tasks.py all     # выполнить все задания подряд
```

Без аргумента скрипт выведет подсказку по использованию.
