# Вопросы для самопроверки

---

## 1. Приведите пример задачи построения регрессии

Прогноз цены квартиры по её площади, числу комнат, этажу и району.  
Цель — **непрерывная величина** (цена в рублях).

Другие примеры:
- прогноз температуры на завтра по данным за прошлые дни;
- прогноз стоимости автомобиля по году выпуска, пробегу и марке;
- прогноз урожайности по количеству осадков и удобрений.

---

## 2. Приведите пример задачи классификации

Определение вида ириса (setosa / versicolor / virginica) по длине и ширине чашелистика и лепестка.  
Цель — **дискретная метка класса**.

Другие примеры:
- определение, спам письмо или нет;
- распознавание рукописных цифр (0–9);
- диагностика заболевания по анализам (болен / здоров).

---

## 3. Приведите пример задачи кластеризации

Разбиение клиентов магазина на группы по схожести покупок (сумма чека, частота, категории товаров) **без заранее известных групп**.

Другие примеры:
- группировка новостей по темам;
- сегментация изображений по цветам;
- выделение типов пользователей по поведению на сайте.

---

## 4. Приведите пример задачи понижения размерности данных

Сжатие 64-признакового изображения рукописной цифры (8×8 пикселей) до 2 главных компонент для визуализации на плоскости.

Другие примеры:
- сжатие изображений (JPEG);
- уменьшение числа признаков перед обучением модели;
- визуализация многомерных данных на плоскости.

## 5. Структура матрицы признаков и целевого массива

Обозначения: `n_samples` — число объектов, `n_features` — число признаков.

| Тип задачи | X (матрица признаков) | y (целевой вектор) |
|---|---|---|
| **Регрессия** | 2D, `(n_samples, n_features)`, числа | 1D, `(n_samples,)`, **непрерывные** числа |
| **Классификация** | 2D, `(n_samples, n_features)`, числа | 1D, `(n_samples,)`, **дискретные** метки классов |
| **Кластеризация** | 2D, `(n_samples, n_features)`, числа | **не нужен** (обучение без учителя) |
| **Понижение размерности** | 2D, `(n_samples, n_features)`, числа | **не нужен** (метод без учителя) |

**Примеры:**

- Регрессия — прогноз цены: `X` имеет форму `(1000, 5)`, `y` — `(1000,)` с ценами в рублях.
- Классификация — Iris: `X` имеет форму `(150, 4)`, `y` — `(150,)` с метками 0/1/2.
- Кластеризация — клиенты: `X` — `(500, 3)`, `y` не задаётся.
- PCA — цифры: `X` — `(1797, 64)`, `y` не используется при обучении.

## 6. Какие свойства исходных данных иллюстрирует `seaborn.pairplot`?

Функция `pairplot` строит **матрицу диаграмм рассеяния** для всех пар признаков. Показывает:

- **распределение** каждого класса в пространстве двух признаков;
- **корреляцию** между признаками (форма облака точек);
- **разделимость классов** — где классы перекрываются, а где чётко разделены.

**Пример на Iris:** пара `petal_length` × `petal_width` разделяет три вида почти линейно — setosa отдельно, versicolor и virginica частично перекрываются. А пара `sepal_length` × `sepal_width` даёт сильное перекрытие классов.

---

## 7. Графики на диагонали pairplot

На диагонали для каждого признака строится **одномерное распределение**:

- по умолчанию — **гистограмма**;
- при `diag_kind="kde"` — **сглаженная кривая плотности** (KDE).

Для Iris диагональ показывает, как значения каждого признака распределены **отдельно по видам**: например, `petal_length` у setosa — узкий пик около 1.5 см, у virginica — широкий пик около 5–6 см.

## 8. Пять шагов решения задачи статистического оценивания в Scikit-Learn

1. **Выбрать класс модели** (`LinearRegression`, `LogisticRegression`, ...).
2. **Выбрать гиперпараметры** (создать экземпляр с нужными параметрами).
3. **Сформировать данные** — матрицу признаков `X` формы `(n_samples, n_features)` и целевой вектор `y` формы `(n_samples,)`.
4. **Обучить модель** — вызвать `model.fit(X, y)`.
5. **Предсказать** для новых данных — `model.predict(X_new)`.

---

## 9. Какую функцию выполняет метод `fit()`?

Метод `fit()` **обучает модель** на данных: подбирает внутренние параметры (коэффициенты, центроиды, компоненты) так, чтобы модель наилучшим образом соответствовала обучающей выборке.

Принимает:
- `X` — матрица признаков `(n_samples, n_features)`,
- `y` — целевой вектор `(n_samples,)` (только для задач с учителем).

Возвращает сам объект модели, поэтому вызовы можно объединять в цепочку: `model.fit(X, y).predict(X_new)`.

---

## 10. Какую функцию выполняет метод `predict()` в обучении с учителем?

Метод `predict()` **выдаёт предсказанные метки** (классы или числовые значения) для новых объектов `X_new`, используя уже обученную модель.

- Для классификации возвращает **метки классов** (например, `"setosa"`, `"versicolor"`, `"virginica"`).
- Для регрессии возвращает **числовые значения** (например, цену в рублях).

Принимает матрицу признаков формы `(n_samples_new, n_features)`, возвращает вектор той же длины.

---

## 11. Методы `transform()` и `predict()` в обучении без учителя

- **`transform(X)`** — преобразует данные в новое пространство (например, PCA проецирует 64 признака в 2 главные компоненты). Возвращает **новую матрицу признаков**, а не метки.
- **`predict(X)`** — для кластеризации (KMeans, DBSCAN) выдаёт **номер кластера** для каждого объекта. То есть тоже «метки», но не классы, а индексы кластеров.

Итого: в обучении без учителя `transform()` меняет **признаки**, а `predict()` назначает **кластер**.

## Кратко

| Метод | Что делает | Тип задачи |
|---|---|---|
| `fit(X, y)` | обучает модель | с учителем |
| `fit(X)` | находит структуру данных | без учителя |
| `predict(X)` | предсказывает метки или значения | с учителем и кластеризация |
| `transform(X)` | переводит данные в новое пространство | PCA, scaler |
| `fit_transform(X)` | fit + transform одной командой | PCA, scaler |
